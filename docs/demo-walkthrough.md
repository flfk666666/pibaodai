# 一条演示怎么录 · Demo walkthrough

这是一份约 60 秒的仓库导览提纲，**尚未录制**。具体 Skills 的使用演示要等首批内容确定后再制作。

## 演示目标

让观众看见：屁宝袋有能浏览的首页，也有 AI 能检索的目录。当前两项想法在孵化中，没有已发布的 Skill；目录会在后续内容上线时帮助 AI 精确选择。

| 时间参考 | 画面 | 可以这样讲 |
| --- | --- | --- |
| 0–10 秒 | 中文首页与口袋横幅 | “我是屁老师，生活里想明白的事、摸索过的工具和顺手的小办法，都往这个屁宝袋里装。” |
| 10–25 秒 | 展示人生阶段与噪音判断的想法卡片 | “这两个是我想继续打磨的方向，现在还在孵化，不是已经做好的工具。” |
| 25–40 秒 | 显示 `llms.txt`，再打开 `catalog.json` | “这个目录也给 AI 看。它会按需求找、按状态区分，不用把整袋东西都倒出来。” |
| 40–50 秒 | 展示分类、独立项目说明与贡献入口 | “有的帮你独立思考，有的解决具体场景。以后大项目单独维护，这里也能把你带过去。” |
| 50–60 秒 | 回到首页，展示首批发布原则 | “先选三个自己反复用过的 Skills，每个配完整案例，再录实际使用。欢迎收藏，或者带个脑洞来。” |

录制时只展示公共页面。后续做使用演示时，若真实回答不符合预期，保留问题并据此改进 Skill，不用参考输出替换它。AI 没有成功读取远程文件时，也应保留说明。
