# 每一分怎样算出来

**后续审查：** [权重与分档实质审计](model-audit-v053.md)发现若干模型矛盾与采集偏差。本页解释既有算式，不替其合理性背书；规则修订与校准仍待完成。

解释版本：v0.5.2。仍沿用v0.5协议及既有节点/权重；本版澄清合成口径并修复地区多参照选择的中间取整问题。它是公开的项目评分模型。

## 先分清四层

| 层 | 保存什么 | 谁决定 |
| --- | --- | --- |
| 原始事实 | 身高、金额、日期、回答、照片、做过的任务 | 使用者提供；评价者记录来源和条件 |
| 转分规则 | 厘米/金额怎样映射到0–100，案例支持哪一档 | 数值曲线与行为锚点由项目声明；行为选档由评价者逐条判断 |
| 合成规则 | 每项占多少、缺项怎么处理、地区替换什么 | 项目公开配置；不能针对结果临时改尺 |
| 结果解释 | 此次材料下的项目分、原值差异、改进方向 | 必须符合前三层，不能升级成人口排名 |

官方资料能支持参照的金额、均高、年份和人群，不能自动证明“高一厘米值3分”或“外形该占20%”。**数据来源可靠、计算可复现、评分模型有效，是三个需要分别检验的问题。**

## 1. 先给子项分，再合成

满分100。36项只有两种基本转分方法，以及F1的组件合成：

**数值项**A1/B2/B3/E1–E5：从原值按节点插值或按档界归档，保存原值、单位、观察日期、规则和区间。下表为默认规则的速查，不替代[机器节点](rubric-v04.json)和[逐项协议](rule-protocols-v05.json)的适用条件。

| 子项 | 中间量与转分 |
| --- | --- |
| A1 全局身高 | 160/165/170/175/180/185cm → 0/20/40/60/80/100；相邻点线性插值，两端封顶。是男性高个偏好配置 |
| B2 力量 | 内置男性85kg训练者卧推60/80/104/130/158kg → 20/40/60/80/100，0kg→0，线性插值；其他体重按协议查同源行，不硬套 |
| B3 耐力代理 | 连续游泳0/25/50/200/800/1609m → 0/20/40/60/80/100，线性插值；不能冒称全面心肺测量 |
| E1 收入覆盖 | r=税后经常收入÷同期必要开支；0→0，0<r<1→20，1≤r<1.5→40，1.5≤r<2.5→60，2.5≤r<4→80，r≥4→100 |
| E2 净资产 | y=本人净资产÷必要年开支；y<0→0，0≤y<0.25→20，0.25≤y<1→40，1≤y<3→60，3≤y<10→80，y≥10→100 |
| E3 现金缓冲 | m=可用流动资金÷必要月开支；0→0，0<m<1→20，1≤m<3→40，3≤m<6→60，6≤m<12→80，m≥12→100 |
| E4 偿付负担 | d=到期偿付÷税后收入；明确无债且偿付0→100；0<d≤0.1→80，0.1<d≤0.3→60，0.3<d≤0.45→40，0.45<d≤1→20，d>1→0；无正收入却有偿付→0；其余缺输入不猜 |
| E5 实际结余 | q=(税后收入−实际总开支)÷税后收入；q<0→0，0≤q<0.05→20，0.05≤q<0.1→40，0.1≤q<0.25→60，0.25≤q<0.4→80，q≥0.4→100；不能以必要开支替代实际开支 |
| F1 家庭支援 | 容量=支持额÷必要年开支；0/0.25/0.5/1/2/3年 → 0/20/40/60/80/100并插值；容量分×50%＋可调用条件锚点分×50%；明确无支持→0 |

**行为/形象项**A2–A6、B1/B4–B6、C1–C6、D1–D6、E6、F2–F6：按材料完整支持的最高锚点选0/20/40/60/80/100。必须写出本项条件、引用材料、命中条件和未覆盖内容，不能整轴凭感觉打分，也不能用任意68/73修饰数字。

例如，虚构某项60档要求能完成基础任务，80档同时要求在不同条件下迁移并说明修正；只有重复做同一基础任务，即使聊了很久，也不会仅因回答数量增加升到80。反过来，已有跨题材料满足80应主动复核，不能因为没问“80分问题”就封顶60。更高档尚未观察不等于能力上限。

**60的三种常见含义不同：**行为项是本题基本档；生活容量项是本题指定容量区间；地区工资是参照的1倍。综合60没有“全国平均人”的含义。23项都得60也可能是粗档位和访谈覆盖的结果，不能据此认定23种能力相同。满分100同样是逐项声明的上限，不能理解成全球第一。

## 2. 权重分两层

| 主轴 | 综合权重 | 六个子项及轴内权重（按1–6顺序） |
| --- | --- | --- |
| A 外形条件与呈现 | 20% | 身高20 / 面部25 / 比例20 / 仪容10 / 穿搭15 / 表达10 |
| B 身体状态 | 15% | 日常功能15 / 力量25 / 耐力20 / 协调15 / 恢复15 / 精力10 |
| C 思考判断 | 15% | 学习15 / 推理20 / 核验25 / 判断20 / 计划10 / 压力调节10 |
| D 实践协作 | 20% | 专业25 / 解决问题20 / 沟通15 / 组织15 / 交付15 / 独立生活10 |
| E 个人经济 | 20% | 收入20 / 净资产15 / 流动缓冲25 / 偿付10 / 结余15 / 持续性15 |
| F 家庭与社会资源 | 10% | 经济支援20 / 居住15 / 照护15 / 协作25 / 平台15 / 家庭约束10 |

每一行轴内权重合计100%；六个主轴合计100%；36项均有正权重。

用百分数数值表示：`gᵢ = 主轴权重 × 轴内权重 ÷ 100`。

例如A1是20×20÷100=**4%全局权重**。A1提高20分，完整综合提高20×4÷100=0.8分；并不是综合直接提高20分。只要全局已知权重不足100%，对已知分的影响还要除以已知权重。

这些比例表达产品取舍：日常形象、独立办事、经济自主各20%，身体和思考各15%，资源10%。它们没有已验证的人群预测效力。相同材料跨项引用必须分别支持不同构念；例如训练动作归力量，肌肉可见轮廓归形象，不能用一条“爱健身”给两项同样的判断。同一笔现金可属于净资产，同时反映流动性，但不能在资产余额里重复相加。

## 3. 轴分：只对本轴已评分项归一

令sᵢ为子项分，wᵢ为轴内权重；已评分项集合记K。

`轴已知分 = ΣK(sᵢ × wᵢ) ÷ ΣK wᵢ`

虚构例：一轴六项权重20/25/20/10/15/10，分数80/60/未知/60/40/60。

`(80×20 + 60×25 + 60×10 + 40×15 + 60×10) ÷ 80 = 61.25 → 显示61`

轴内尚缺20%权重。这里61是已知80%的归一值，不能声称整轴已完整测得61，也不能把61乘完整主权重再进入综合。

## 4. 综合：直接用36项全局权重

令gᵢ为全局权重，W=ΣK gᵢ。

`已知综合 S = ΣK(sᵢ × gᵢ) ÷ W`

**不能先把六轴取整数再平均，也不能让缺得多的轴先恢复满额权重。**填写数34/36和可评权重93%是不同量；不按填写率奖励或惩罚本人。

两种“贡献”必须分开标名：

- 对完整综合的已知贡献：`sᵢ × gᵢ ÷ 100`。固定满额分母，便于加上待测项。
- 对已知综合的归一贡献：`sᵢ × gᵢ ÷ W`。它们相加等于未取整的已知综合。

轴贡献是该轴各项贡献之和。中间数保留精度，显示才四舍五入；历史已存的近似单项与精确重算须分别说明，不能一边声称精确一边把显示值送回计算。

## 5. 已知分和完整范围不是同一个数

每项下上界为lᵢ/uᵢ。未知默认0–100只是展示逻辑边界，**不是认定本人得0、100或默认中间50**；某组件已知时应收窄对应范围。

`完整综合下界 L = Σ(gᵢ × lᵢ) ÷ 100`

`完整综合上界 U = Σ(gᵢ × uᵢ) ÷ 100`

已知综合分母W，完整范围分母100；它们回答不同问题。前者描述这次已评分材料，后者展示全部项目在声明缺口/粗估条件下可能落在哪里。不是S的统计置信区间，也不能把范围中点冒充最佳估计。假定各项端点都能同时成立的边界是宽松包络，未建项目间依赖模型。

虚构仅有10%权重未知、其余都60：已知分60，完整范围54–64。未知项后来得到20，则完整分56；不是人突然退步，而是新资料补齐了分母。

数值区间分别换算端点；明确的条件冲突依协议给范围。不为“看起来谨慎”随手加减10。只有自报、没有核验，也不自动减分；来源、日期、代理任务和未测覆盖分别说明。页面整数范围下界向下、上界向上取整，不表示原始上下界恰好是整数。

## 6. 换地区时，替换哪些标尺

默认情景保持本人当前生活，只换以下参照。重算子项后沿同一36项权重链合成六轴和综合。B/C沿用同一任务规则，不能冒充当地人口分位。

| 项目 | 地区计算 | 解释 |
| --- | --- | --- |
| A1 身高 | clip(60＋3×(本人cm−当地均高cm),0,100) | 相等60；每厘米3分和封顶是项目选择，不是审美研究结论 |
| E1 工资 | clip(60＋20×log₂(本人税前年化CNY÷参照税前年化CNY),0,100) | 1倍60、2倍80、半倍40；名义汇率换币，不是购买力或人口排名 |
| E2 资产 | 净资产÷当地参照年工资，按原资产年数档界 | 工资等价资产年，区别于全局的必要开支年 |
| E3 现金 | 可用现金÷当地参照月工资，按原现金月数档界 | 工资等价现金月，不能称当地还能生活几个月 |
| F1 支援 | 家庭支持÷当地参照年工资求容量分；调用条件保持本人事实，再各50% | 只改变容量坐标，不把潜在支持记为个人资产 |

币种换算统一使用报告登记的同一天汇率，月/周原值明确年化因子；参照必须附来源、年份、年龄与税前税后口径。尽量匹配出生队列±3年，缺精确窗口时明确实际年龄组。**换成同一币种解决了单位问题，不会消除税制、工时、统计人群、年份差别。**

多个工资参照分别生成完整情景。主显示选未取整的已知综合较低者，整段范围包住各情景边界；并列列出均值/中位数/不同雇佣范围，不能平均成虚构基准。较低是本项目的展示约定，不是统计上更正确的一种。

例：虚构身高187cm，当地均高170cm，原算111分→封顶100；均高175cm时96分。均高更低也可能同为100，要同时看厘米差和封顶前值。外形轴还含另外五项，身高优势不等于外形整轴100。

仅`relocation_review`讨论迁居后的语言、住房、照护和当地协作。未知保持未知，不能因点某个国家就给专业或思维扣分。迁居情景覆盖变化时，单看归一总分可能反向升高，必须同时看覆盖和完整范围，不能解读成搬过去更强。

## 7. 如何判断这套规则值得继续用

计算正确只是第一关。还需要固定同一份材料做重复评阅，看同一/不同评价者选档是否一致；复核交叉案例是否遗漏、是否重复归因；预先固定权重再做合理变动的敏感性检查；用后续真实表现检验高低档是否有解释力。尚无这些结果时，不声称已完成校准。

当前合成默认：20分档距可视为等距、不同构念能共用刻度、强项可部分补偿弱项、权重对所有人适用。它们都是待验证的模型假设。安全或关键资格不能靠高身高抵消；有此用途应另设明确门槛，不把综合分当通行证。

**读报告的顺序：原值与事实日期 → 子项规则及命中条件 → 权重和贡献 → 已知覆盖/完整范围 → 地区换尺。**分数变化先查资料、规则、参照和分母是否变了，再讨论个人进退步。
