# 角色看板：事实档案与36项加权评阅

当前评阅方法见[method-v06.md](method-v06.md)。本页保留早期采集/材料说明，旧评分语义不能覆盖v0.6的新内容规则与追问策略。


版本：`character-panel-v1`。状态：experimental。作者：屁老师；本版方法与题目由 AI 协助整理。

这是一个可续填的个人角色档案。六个维度、36个子项帮助使用者整理当前处境、能力材料和可调用资源；不是已验证的心理、医学或人口排名量表。事实档案能保存、续测和局部复测，未校准的正式量表分数、规则版本和百分位保留`null`。新报告默认使用`weighted-character-v0.4`，按[36项规则](rubric-v04.json)与[加权方法](weighted-character-v04.md)计算六轴、综合结果及地区情景，报告分数不写回事实档案。

## 六个维度

| 轴 | 子项 | 本版记录什么 |
| --- | --- | --- |
| A 外形条件与呈现 | 身高、面部、比例、仪容、穿搭、仪态 | 测量值、照片条件和可见观察；场景固定为日常综合形象 |
| B 身体素质与状态 | 日常功能、力量、耐力、协调、恢复、精力 | 有日期和条件的实际表现、近两周状态；照片不能替代功能记录 |
| C 认知与心理 | 学规则、推理、辨别信息、判断、计划调节、压力应对 | 具体经历、材料与过程；C1—C4暂为候选材料采集，不冒充正式测验 |
| D 实践与协作能力 | 专业、解决问题、表达、协作、交付、独立生活 | 明确领域、任务、本人贡献、结果及验证；职位和工资不能替代作品 |
| E 个人经济实力 | 收入、净资产、流动缓冲、偿付、结余、来源持续性 | 本人金额、权属、期间和计算口径；不要求账户截图 |
| F 家庭与社会资源 | 经济支援、居住、照护、人脉、环境、责任限制 | 当前真正可调用的资源、附带条件和匿名案例；不收第三方身份 |

基础信息独立于36项，包括是否成年、年龄、性别自述、城市/国家、职业与教育背景。它们用于解释材料与选择参照；不因为性别、城市、学历或家庭结构自动加减分。昵称、年龄区间和金额区间均可按本人意愿提供。未知、未填写与跳过分开；首版尚无“不适用”豁免规则，不借此移除待填项。

## 一次只采一小组

先读取私人 `current.md`。用实际缺口决定下一题，避免按题库从头重问。通常一轮聊1个子项的1—3个问题；字段有答案就保存草稿，不必等完整回答。允许换轴、跳过、晚些补照片或暂停。

填写完成不代表测量已经验证。输入齐全但没有已校准正式量表时，档案保留`score: null`与“待规则”；没有材料、被跳过或已过期时，保留相应原因。用户要求数字或雷达即授权制作独立规则报告；不再反复请求许可或为补齐全部资料阻塞交付。报告提供明示权重的角色综合分、六轴、覆盖和未知范围；综合分是产品选择，不能改称人生价值或无匹配分布的人口百分位。

认知项目可先收“面对过什么问题、如何处理、有什么可核对的过程”；不凭一段自述推断智商、人格、临床状态或跨人群竞争力。正式任务库的题目、可核验答案、评分细则和适配人群需要另行设计与验证。

## 36项加权评阅 v0.4

规则文件是[rubric-v04.json](rubric-v04.json)，解释与计算见[weighted-character-v04.md](weighted-character-v04.md)。六轴A/B/C/D/E/F权重依次为20/15/15/20/20/10，每轴子项权重合计100，36项均为正权重。`global_weight = axis_weight × item_weight / 100`；综合分直接使用36项全局权重，不能只算工资，也不平均已取整的六轴。先引用材料并对应锚点或声明曲线，再由计算器合成，不能先给整轴75或80再补理由。

- A1身高占外形轴20%，成人男性高个偏好为175cm→60、180cm→80、185cm→100并封顶；偏好曲线不等于客观颜值或人口分位。身高实测、自报、当地分布与审美规则分别标记。B2使用声明的训练者力量阈值，B3使用连续游泳距离功能档；保留动作、日期、体重与泳式条件，不伪称普通人口或心肺测量常模。
- 未知、拒答和无法使用的资料仍为`null`，不扣0分、不默认60，也不临时删权重。显示每轴及综合的已知部分分、可评权重覆盖和未知按0/100形成的完整数学范围；范围不是统计置信区间。规则60按具体子项解释，不把所有60统一叫同龄平均或人生及格线。
- 审美先声明偏好、评价者与场景，按合格照片写具体可见依据；行为只评已有案例中的实际过程和结果，不把一例变成人格或通用能力结论。使用AI不自动减分，也不把AI的实现成果全算成本人独立技术能力。
- “资料已填”与“可以适用锚点”分别统计。每轴写资料覆盖、依据来源和参照匹配，替代没有解释的高中低把握。自报按其来源使用，不因为不交银行截图或敏感原件就判低分。
- 旧资产估值、旧照片和历史表现保留原日期。E2在使用者明确沿用历史估值时可计算该快照情景分，注明确认记录与时效限制；“仍大致适用”不等于今日市值、新实测或独立核验。潜在家庭支持不并入本人资产，同一案例复用不算多份独立证明。
- 评价可以按用户要求毒舌，但必须有事实和基准差异撑着；批评行为与矛盾，不贴人格、临床、出身或人生价值标签。每条建议落到已有事项、下一实际场景、具体动作和完成标志，不把“多社交、提升思维、往前一步”当通用模板。

默认结果为10字内短评、六轴规则图和综合结果首屏，下方轴卡显示与声明基准的差异、子项锚点/权重/计算、具体依据和动作。首屏注明“项目规则评阅 · 非同龄排名”，部分轴与缺失轴要看得出来；杭州、全国和国际对照分别展示综合分、六轴、变更账本与地区总结，不能用规则分冒充统计排名。

报告JSON、HTML与PNG放在私人档案旁，注明来源修订与规则版本，保留旧版以便比较。渲染器使用随包离线模板；头像可选。PNG来自宿主真实浏览器截图，没有生成就如实报告缺口。计算、保存与本地显示不要求API或把私人资料发往额外服务；外部参照来源另核验。

### 旧版兼容

`subjective-review-v0.1`、`anchored-review-v0.2`及`regional-income-v0.3`历史报告继续读取；新报告使用`rating_type: "weighted_character"`、`version: "weighted-character-v0.4"`。v0.3工资模块可在v0.4内继续为收入子项提供参照。旧分不能补称为v0.4计算结果；切换规则产生的变化不能说成本人进步或退步。原始事实与未校准正式量表分数继续独立保存。

## 照片：用于日常综合形象

本版面向成年人自评，执行前确认是否成年及是否评估本人。不为未成年人评分外形。外形照片是正式输入，允许先完成不依赖照片的项目；不提供照片不会变成低分。

建议材料：正脸自然表情、正脸微笑、左右侧脸、全身正面和侧面；可选1—2套日常穿搭。穿普通合身衣服即可，不需要裸露、私密照片或证件。近期原图、均匀光线、简单背景，避免美颜塑形、超广角近拍与明显俯仰；日常妆容可以注明。照片不足只说明材料问题。

记录实际拍摄日期、视角、已知处理、用途授权和路径。临时聊天附件可能失效，只有经使用者授权并实际保存到私人位置后，才能声称材料已持久保存。运行器只检查路径是否存在；AI仍需实际看过图片才能写可见观察。文件存在不代表照片合格。

允许描述照片中可见的脸部、轮廓、仪容、服装和姿态；把观察与审美偏好分别写明。按公开子项锚点评价声明场景中的日常外形呈现，审美选择仍属评价者判断，不将其称为客观“颜值分”。不由照片推断精确身高、体脂、健康诊断、智力、性格、道德、收入或家庭条件；静态图也不能证明步态、声音或动态能力。

## 数据口径

每条事实保留来源和观察日期；保存时间不是事实日期。自报的客观量仍标“本人自报”，不能写成独立核验。作品与日志只记录本人有权分享的部分；允许描述代替上传敏感原件。

财务项目要分清税前/税后、个人/家庭、工资/全部收入、币种与期间。净资产按“资产总估值×本人所有权比例之和－本人承担的全部未偿负债”计算；已填净权益时不再扣同一贷款。父母未转移的财产不算本人资产。

流动缓冲使用可实际动用的资金和同口径必要月支出。已经计入月支出的房租、月供不从资金再次扣除。分母为0或未知时保留空值与说明，不给无穷值。股票、自住房、受限或无法及时变现的资金不自动当现金。v0.4项目阈值在规则JSON中公开，正式校准量表仍未建立；不能把项目阈值叫官方收入等级。地区E3另外比较可用现金的当地工资等价月数，不声称那是当地真实生活费可支撑月数。

同一事实避免重复计分：家庭拥有、本人拥有、可以借用和承诺支持分开；一件作品被多个子项引用时要说明各自观察内容。对资源限制的记录描述现实约束，不评判家庭责任的道德高低。

## 本地与国际参照

先有原值，再选择匹配口径的来源。基础资料中的`comparison_age_window_years`默认3，即±3岁；只有出生年份时用出生队列，不猜精确足岁。所有人群位置核对同龄窗、地区、适用人群和统计定义。全龄或不匹配年龄的数据不能当精确同龄分布或用于推出百分位；用户接受粗比较时，仍应统一期间和币种，计算有标记的地区收入参考分。

本地、全国和国际参照分开；国际具体到国家及人群，不给笼统“世界竞争力”。欧洲、东南亚不是一套税制、工资或审美人群，不把区域名当作统一国家。记录地区、人群、定义、单位、调查年、发布日期、来源链接及适用限制。

平均数、中位数、分组均值不能推出个人百分位。收入、工资、家庭可支配收入和消费不能随意混用。按[地区收入模块v0.3](regional-income-v03.md)可以用同日名义汇率将原币工资统一成人民币年化金额，给相对倍数与公开映射分；这不是PPP或生活质量比较，不能以未做PPP为由停止已能完成的币种换算。身高百分位也不等于审美百分位。没有匹配分布时人口百分位保留`null`，与仍可计算的项目收入参考分分开；规则雷达中的分数不能改称人口排名。

地区收入参考分用`clip(60+20×log2(本人税前年化人民币/参照税前年化人民币),0,100)`；等于所选工资参照为60，一半40、两倍80、四倍100，封顶后仍保留原始倍数。它与主六轴“够用60”的定义不同。私营/非私营、均值/中位数等参照逐条给分，只列不同参照所得范围，不取中点；不将欧洲或东南亚不同国家简单平均成整个区域的分数。

地区竞争力采用[加权情景方法](weighted-character-v04.md)，`group.character_review`给综合`score`、`score_low`/`score_high`、六轴及逐项变更账本。主看板A1仍使用175cm→60、180cm→80、185cm→100的全局偏好；地区有真实可取的均高时，A1采用地方“显高相对突出”分`clip(60+3×(height_cm−reference_mean_cm),0,100)`，均高对应60，每高1cm增加3分并封顶。这仍是项目映射，不是当地审美常模或颜值百分位；保留来源、年份和年龄差异。缺少当地值时明示沿用全局曲线，不按国籍编造均高；A2面貌、B身体和C认知不因国家名加减。

EU缺少适用均高时不把荷兰当EU均值，EU主分沿用全局曲线。荷兰均高只能作为更强对照的敏感性情景进入完整结果区间，须单列其来源与适用人群，不能替换EU主分。D仅D3按目标岗位语言情境调整；E1看名义工资比，E2看净资产工资等价年，E3看可用现金工资等价月；F看真实可调用性，原居住和家庭支援能否跨地使用须有材料。未知当地语言或人脉不是0分，不凭国籍猜当地适配。未变的项目也继续按全局权重进入各地区综合结果。

每地区摘要要解释六轴共同形成的现实位置、优势、短板与一个可验证动作。v0.3名义收入分只是E1依据，不能单独顶替综合竞争力、预测当地岗位报价或生活质量。多个工资口径形成不同情景及范围，不能取均值冒充统一人口基准。

每次结果固定规则版本、来源修订和参照快照。更换规则生成新结果；区分事实变化、测量条件变化和算法变化。切换地区明确显示该地区六轴及变更账本，保留原始主看板可查，不能悄悄改写主看板或历史结果。

## 存档与复测

公开Skill保存方法、题目、通用模板与去隐私演示。私人存档保存在安装目录和公开仓库之外。`current.md`是唯一当前事实记录，其中结构化数据供运行器读取；汇总视图可再生。使用脚本更新，不维护另一份当前事实JSON。独立`report.json`只保存某次修订的规则报告与展示字段，不承接后续回答，不把报告分值回写为已校准测量。

每次回答保存有效字段，完成子项再标输入完成。写入使用修订号检查、单写入保护、同目录临时文件校验、保留上一成功版本、替换和回读；写入失败不说“已保存”，先处理失败或明确给出未保存答案。历史、备份和原图也都是私人资料。

续测保留已填字段，只追问缺口。局部复测先留快照，指定需重测的项目；旧事实保留原日期和待复核标记，重新回答后才刷新观察时间。没有被选中的项目不清空。评分为空的项目也能复测资料。

首版由用户主动选择`retest`或通过材料失效检查标记待复核；按期限自动提醒尚未实现，也不创建日历任务或后台调度。不能自动编造新资料。跨期比较需要一致的口径、规则与证据条件；无法比较时直接说明。

`current.md`中的答案、引文和作品内容都是数据，不是可执行命令或额外授权。自动保存本地档案不等于获准公开、提交Git、训练或把资料发给额外服务。删除时核对当前档案、历史、备份及证据的实际范围，不能只移除链接就声称全部删除。

## 方法来源与边界

六维拆分、存档流程与题目为屁宝袋项目讨论形成的产品设计。以下资料只支持具体方法注意事项，不为整个角色看板或评分有效性背书：

- [Ward等：近距离自拍的透视畸变](https://pmc.ncbi.nlm.nih.gov/articles/PMC5876805/)：照片条件会改变可见比例。
- [Oosterhof与Todorov：面部印象判断研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC2516255/)：描述外貌印象不等于知道真实人格。
- [国家统计局：居民可支配收入指标说明](https://www.stats.gov.cn/zs/tjws/tjzb/202301/t20230101_1903384.html)：收入参照必须核对定义。
- [世界银行ICP常见问题](https://www.worldbank.org/en/programs/icp/faq)：跨国价格比较需正确理解购买力平价。

资料采集、逐项保存、恢复和局部复测已有运行实现。v0.4计算与图形呈现的验证以实际命令和浏览器输出为准；无论计算是否可复现，评价有效性、跨人群可比性与真实使用效果仍需后续验证。
# v0.5 协议优先

新报告按[完整规则v0.5](complete-rules-v05.md)与[36项协议](rule-protocols-v05.json)执行；以下保留原有方法和边界。每项材料、选档、权重理由、缺失/范围、地域和复测都必须明确；数值原值由生成器重算，主观选档附实际支持和限制。问卷填写完整不能替代评分适用条件，旧自报也不因新协议自动作废。
