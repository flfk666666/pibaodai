# 角色看板v0.6：表现、材料和地区分开

版本：`weighted-character-v0.6` / `character-rules-v0.6`。36项完整定义、锚点、数值参数及追问条件见[rubric-v06.json](rubric-v06.json)。这是可迭代的项目评阅，不是已校准的人群量表。

## 这一版改了什么

六维及36项继续有明确分数，材料不足和能力不足分开。旧v0.5报告和原事实保留，新分数变化解释为规则或新资料变化，不写成人突然进步。

主轴和轴内六项都用`weight_units: 1`起步。每轴归一为1/6，子项在轴内1/6，全局1/36。等权是透明默认，减少在缺少实证时擅自强调某个构念；不是证明所有因素现实作用相同，更不是唯一科学权重。以后特定目标的权重可单独配置和命名，不能针对某人想要的结果临时调参。

行为/形象用0/25/50/75/100五个**内容锚点**：按本题实际失效、明显困难、基础应用、自主有效、更高要求表现判定。条件项B1/E4/F6另按功能/负担定义，不强制证明运动员能力、无任何人生责任或经历危机。数值项可以连续得分。

换五档本身不会改善效度，也不保证分数分散。修订重点是条件内容、构念边界、证据覆盖和中立追问。

## 明确修掉的偏差

- B1只评日常活动独立性，不用卧推给它升档；B2只评已声明的推力任务。
- B3改为连续游泳任务表现，不用单一距离冒称全面心肺能力。
- B4评明确动作控制范围，不从普通生活没有受限外推运动协调优秀。
- B5为睡后恢复；B6为清醒任务中的精力影响，不能因为“能完成普通工作”同时命中两个重叠档。
- A3可限定为实际可见轮廓；未见身体部位单列覆盖，不用缺完整照片否定已有材料。A2/A3等不因角度、日期、照片数量自动升档。
- C2工程逻辑与未测数量能力分开；C3按风险、领域和真实核验行动，不能由低风险闲聊概括全部专业判断。
- E6只评价所述期间经常收款履约，正常到账可达到本项100；未来过渡归资产/现金等项，单一稳定工资不因没有副业或没失业过而卡基本档。
- E4/F6是偿付/责任约束条件条，高分表示当前负担低，不混称财务能力或家庭质量满分。
- F1可调用性作门槛：明确不可用→0，未知→null并保留容量边界；本人具体自报可用有效，不强要账户或书面证明。容量不能平均补偿不可调用性。

## 每项表现与材料分栏

每项至少包含：

```json
{
  "id": "D4",
  "selected_anchor": 75,
  "evaluation": {
    "status": "provisional",
    "reason": "虚构示例：已自主拆分任务、协调交接；复杂变更中本人作用待补。",
    "evidence": [{"source_type": "authored_fictional_case", "summary": "虚构团队任务过程", "observed_at": null}]
  },
  "coverage": {"level": "usable", "scope": "已描述的普通协作", "gaps": ["复杂变更中的取舍"], "higher_unassessed": true},
  "score_range": [75, 100],
  "range_reason": "已有协调的积极线索，75与100的内容区别尚未问明。",
  "followup": {"positive_signal": "自主协调过任务依赖", "question": "挑一次最棘手的变更，说本人改了什么、结果怎样？", "status": "pending"}
}
```

这是编写的虚构格式示例，不是真人评分。没有积极线索时不凭空给75—100范围；没有可评表现则保持`selected_anchor: null`，不能补默认50、60或75。

`coverage`只说明看到了哪个场景、时间、材料和未测部分；它不是分数乘数。不因材料多奖励分，不因说得简略就认定不会。本人具体自报、实际照片和案例可正常使用，来源和观察日期分别保留。

材料支持相邻两档的明确候选范围但暂不能选档时，可以有`selected_anchor: null`、`evaluation.status: provisional`、`score_range`和具体`range_reason`。不能填区间中点作能力估计，也不能无材料就擅自缩小0—100边界。

## 自适应追问

依次执行：

1. 先复核已有跨题材料，避免重问。
2. 有本项自主取舍、复杂条件、迁移或明确高任务表现的**积极线索**，且一个未明条件可能改变判断时，问一个中立的区别问题。允许失败、未知、无此经历和跳过。
3. 没有明显高档迹象、当前范围已可评时继续下一项，保留更高要求尚未观察；不是下“不能更高”的结论。
4. 低档必须由明确失效、依赖或实际困难支持。没问到、没交材料和回答不完整，不是失败证据。
5. 已明确暂缺或拒答的材料不反复索要；每次有效回答/跳过先保存，再局部重评受影响项。

## 数值曲线和依据层次

| 项 | v0.6计算 | 性质 |
| --- | --- | --- |
| A1 | 高个偏好155/165/175/185/195cm→0/25/50/75/100，线性插值 | 男性高个偏好配置，不是颜值常模 |
| B2 | 外部男性85kg训练平台负荷60/80/104/130/158kg→20/40/60/80/100 | 负荷节点来自平台；转分与插值仍是项目选择，只覆盖该动作 |
| B3 | 连续游泳0/25/50/200/800m→0/25/50/75/100 | 任务容量曲线，不是全面心肺测量 |
| E1/E2 | x为收入覆盖倍数/净资产必要开支年；100×max(x,0)/(max(x,0)+1) | 连续容量指数，避免任意档界骤跳；基点未作人群校准 |
| E3 | x为自由现金必要开支月；100×x/(x+3) | 3个月为选定解释基点，不宣称调查验证了本函数 |
| E4 | 100×(1−clip(到期偿付/税后收入,0,1))；明确无债且偿付0→100 | 低偿付负担；缺债务/期间不能推无债 |
| E5 | 同期间100×clip((税后收入−实际总消费)/税后收入,0,1) | 保留收入比例，不是能力分；必要开支不能替代总消费 |
| F1 | 先判断调用门槛，再按可用支持必要开支年计算100×x/(x+1) | 自报可用接受；不平均补偿明确不可用额度 |

有限输入的渐近曲线不必达到100，100是数学上界。各参数与共同刻度仍是产品选择，不能借连续函数或等权宣称已建立科学效度。来源参考：[StrengthLevel](https://strengthlevel.com/strength-standards/bench-press/kg)、[Fed2022应急缓冲调查](https://www.federalreserve.gov/publications/2023-economic-well-being-of-us-households-in-2022-expenses.htm)、[OECD/JRC综合指标方法](https://www.oecd.org/en/publications/handbook-on-constructing-composite-indicators-methodology-and-user-guide_9789264043466-en.html)。

## 地区不再共用工资惩罚四项

每个地区都显示完整六维参考分，并列三类坐标：

- 身体条件/任务：身高本人值、均高差、真实可用的人群分布；卧推/游泳表现原样保留。没有个体分布不从均值/均值置信区间编百分位。
- 财务：本人真实现金缓冲月数和资产容量；地区工资仅影响E1收入坐标。E2/E3/F1继续用真实必要开支和实际调用条件，不能把同一个高工资分母当四份独立证据。
- 资源/落地：真实住房退路、照护、协作与工具；迁居后的工作语言、岗位资格、实际报价、现场资源单独待核，未知不扣思考或专业。

地区A1突出坐标为clip(50+2×厘米差,0,100)，E1为100×本人税前年化/(本人税前年化+参照税前年化)，均明示项目映射。其他子项不凭国名改分。地区差异大小由资料和声明规则产生，不为制造差距调参；参考合成不是完整当地竞争排名。

美国CDC2021—2023男20—29岁有真实身高分位原表，可显示相邻已发表分位的区间，保留宽龄与调查年份，不自行线性插出精确百分位。[CDC原表7](https://www.cdc.gov/nchs/data/series/sr_03/sr03-050.pdf)。各国年轻**家庭**资产不能直接当本人**个人**资产百分位。

## 合成、验证与历史

分数保留原精度，最后显示整数。已知分以已评分权重归一；完整范围用全部100权重计算，来源为明确原值区间、候选档或缺项数学边界，不是已知分的统计置信区间。两种贡献分别写清分母。

`review_v06.calculate_report(report)`为独立引擎；`render_dashboard.py`按版本自动选新模板。旧引擎/规则和历史报告继续可读。软件检查验证约束与计算，不代替重复评阅、预测效度或真实使用反馈。
