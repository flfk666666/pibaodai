# 评分模型合理性审计 v0.5.3

后续v0.6已实现对应的构念、覆盖分离与调用门槛修订，见[新方法](method-v06.md)和[新规则](rubric-v06.json)。本文仍是v0.5历史实质审计，不代表v0.6仍沿用所有旧缺陷；新曲线与权重也未冒称完成科学校准。


审计日期：2026-10-27。对象：现行v0.5协议、v0.4基础节点/权重与v0.5.2计算实现。

**本文是模型审计，不是新评分协议；没有修改引擎、权重、分档或任何人的历史结果。** 本文只讨论通用规则，不包含真人资料或私人评估结果。

## 审计结论

现有模型可以依据材料复算，但**尚未验证主轴/子项权重、行为档距、数值档界及综合分能否合理表示“完整角色水平”**。全部权重均为项目取舍，不是从现实结果估计出的贡献率。部分原值和参照有现实数据来源；“这些数据应该换成多少项目分”仍主要由项目制定。

需要同时审查三件事：

1. **测的是什么。** 身高、上肢推力、收入覆盖、照片中的形象、某次沟通表现是不同构念；名称不能比实际测到的范围更大。
2. **证据够不够。** 材料的时间、场景、数量和可重复程度决定能判断多大范围；不能把资料多自动当能力高，也不能把高档未问到自动当能力低。
3. **怎样合成。** 把0/20/40/60/80/100当等距，再用固定权重相加，默认不同构念可比较、可部分互相补偿。这些都是模型假设。局部档案的敏感性复算可检查算值如何变化，仍没有覆盖目标人群和用途的重复评阅或结果校准证据。

## 为什么容易出现很多60分

现行规则的六档适合做粗略描述，却尚未证明适合区分相近能力。大量60至少可能由以下机制产生，不能直接解释成人群真实分布：

- **60是宽入口。** “普通任务基本能完成”覆盖很多表现差异，细分信息被压到同一档。
- **80/100经常同时要求复杂、重复、跨场景、记录充分。** 档位同时改变任务要求和材料要求，证据不足被映射成较低能力分。
- **问答通常先采一个普通实例。** 没有按高档条件补充辨别性追问，许多项目只能停在基本档；“没问到”不是“不能做到”。
- **档界有重叠。** 例如B6的60是困倦但普通任务仍能完成，80是普通任务通常能持续完成并有精力说明；没有足够清楚的严重度、频率和影响界限，同一材料可能同时符合。
- **阈值平台效应。** 金额或任务表现变化，只要没有跨过阶梯节点，分数仍不变；小数计算正确也不会产生更好的分辨率。
- **普通案例被扩成整项能力。** 单个任务只能支持其范围；如果标题过宽，60既显得像总体评价，又只是单例证据下限。

改法不是给所有60改成70，也不是为数字分散而任意加小数。应先明确要测的表现，分开“表现评价”和“证据覆盖”，设计能区分相邻档的任务或追问，再检验不同评价者是否得出相近结果。

## 为什么地区差异容易被压小

默认主轴权重为A/B/C/D/E/F=20/15/15/20/20/10。当前生活换参照仅改变以下组件：

| 可随地区参照改变的组件 | 原始全局权重 |
| --- | ---: |
| A1身高 | 20%×20%=4% |
| E1收入 | 20%×20%=4% |
| E2净资产容量 | 20%×15%=3% |
| E3流动缓冲容量 | 20%×25%=5% |
| F1支援容量的一半 | 10%×20%×50%=1% |
| **实际组件合计** | **17%** |

五个完整子项的权重合计18%，但F1只有容量一半随工资参照变化，另一半可调用条件保持原事实，因此**在参照充分、资料状态一致的通常情景中，真正地区敏感的组件为17%，其余83%固定**。特殊的“明确无支持→0”分支或缺资料状态应另查，不能把17%机械套在所有异常路径上。

这并不自动证明17%过小，也不证明应把它调大；它说明当前结果主要是“同一个人的现状指数，局部替换地区坐标”，不能包装成当地整体人口竞争排名。缺项归一时还应同时看已知分母，不能把原始权重直接当作当前有效占比。

压缩差异还来自：

1. **身高封顶。** 不同均高差可以同时命中100，继续增大原值差不再改变单项分。
2. **阶梯档界与封顶。** 资产、现金在同一阶梯档内变化不会变分；支援容量是分段线性，档内仍会变化，只在封顶后停止增分。不能把两类曲线混为一种。
3. **共同工资分母。** E1、E2、E3及F1容量都除以同一个当地工资参照。参照工资变化会让多项同向移动，不是四份独立的地区证据。用工资等价容量还有解释价值，但不能当作独立验证的收入、财富、生活成本和家庭资源排名。
4. **多数能力使用同一任务标准。** B/C及大部分D/F不因国家名自动改变；这符合不凭地区猜能力的原则，但也意味着没有完成这些能力的当地位置比较。
5. **综合平均与取整。** 单项变化经过较小全局权重后，再显示为整数，细小差异会消失。

因此，地区模块应分别呈现原始工资/均高差、现金的真实生活缓冲、工资等价容量及有材料的迁居条件。需要更完整的当地竞争力时，要先定义目标情景并取得相应人群/岗位/资源资料；不能仅为“看起来差异够大”临时放大权重或曲线斜率。

## 四个可复核的模型反例

### 1. 明确不可调用的家庭支持仍得到50

**以下是完全虚构的规则反例，不是真人资料：** 潜在支持250000元、必要年开支50000元、可调用条件分0。当前容量达到封顶100，程序按50/50平均得到`100×0.5＋0×0.5=50`。

但可调用条件0的定义是明确不可提供给本人，协议又声明不能给本人应为0。不可用的容量仍能补偿不可调用性，与“可调用支援”构念矛盾。**这是待修的模型问题；本文未更改引擎或实际报告。** 下一版应先明确不可用门槛，或将潜在容量与可调用性分列；不能只选择一个新系数掩盖矛盾。

### 2. B6同一材料可符合两档

完全虚构描述：“有时困倦，但多数普通工作日能持续完成任务，并能解释精力受影响的情况。”它既可符合60，也可能符合80。评价者选择哪档不应靠语气；先补清楚任务负荷、影响频率与是否中断等可辨条件。

### 3. 卧推成绩串入日常功能

B1应评价日常功能，B2评价选定力量任务。即使一个人有很好的卧推成绩，也不能由此额外证明走楼梯、搬物和普通活动完全不受限；同一成绩不应不加区别地给两项增加判断。

### 4. 照片覆盖丰富被当成形象更好

两份材料中的实际形象可能相近，仅一份多了几个日期或角度。如果因此从60升到80/100，变化首先是评价覆盖与稳定性证据，并不必然是形象质量提高。应分别记录“当前可见评价”和“证据覆盖”，不能靠免责声明继续把它们合在一个高低分里。

## 建议修订顺序

1. **先修构念与证据混合，以及明确矛盾。** 对齐名称和实际任务范围，处理F1不可用补偿、B6重叠、B1/B2串项；把能力/条件表现与材料覆盖分开。保留旧版结果供追溯。
2. **再补具有辨别性的访谈或任务。** 只追问确实能区分相邻档的内容；工作与自驱、低风险闲聊与重要决策、普通日常与复杂变更分开。未遇到某种危机不等于没有应对能力，可另设明确的情景任务，但情景回答和真实经历不得混称。
3. **然后讨论权重方案。** 先定义使用目标，再比较几套预先声明的价值权重；检查相关项和共同分母，明确哪些短板不能被其他优势补偿。不以某个人是否得到预期分数决定权重。
4. **最后做重复评阅、敏感性与校准。** 固定材料由同一/不同评价者重复选档；检查相邻档能否稳定区分、不同任务是否覆盖同一构念；在合理权重/映射变化下观察结论是否稳健；有后续现实表现时再检验解释力。

在这些步骤有结果之前，现有指数可以作为带版本的实验性整理工具，但不能因公式通过测试、引用了官方数据或界面漂亮，就声称权重和分档已被现实验证。**修订目标是让结论更可靠，不是临时把分数或地区差距调大。**
