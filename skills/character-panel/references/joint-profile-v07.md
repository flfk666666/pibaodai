# 角色看板 v0.7：把条件连起来，再下整体判断

呈现入口：`presentation_version: joint-profile-v0.7`。评分仍为 `weighted-character-v0.6` / `character-rules-v0.6`，继续使用 [v0.6 方法](method-v06.md)与 [36 项规则](rubric-v06.json)。本页对应 [joint_review.py](../scripts/joint_review.py)和 [joint_context.py](../scripts/joint_context.py)。

v0.7 增加“哪些条件共同成立、什么会卡住它、哪些尚未确定”的解释层。它不重写原事实、36 项分数、权重、轴分或地区参考分，也不再合成一个新总分。数值计算可复算，不表示内容锚点、审美偏好、权重或联合门槛已经获得人群效度验证。

## 三种内容分别呈现

| 内容 | 依据 | 能回答什么 |
| --- | --- | --- |
| 原值与既有六维分 | 原始回答、照片、任务及 v0.6 曲线/内容档 | 已观察到的表现与条件怎样计分 |
| 联合判定 `joint_assessment` | 本页公开的 AND / 替代路径规则 | 主要条件能否一起支持一个结论，有没有不可被平均抹平的短板 |
| 地区参照与条件情景 | 对应统计来源、年份、人群或明确假设 | 相对哪个坐标，以及在指定条件下容量怎样变化 |

例如，高个、面部匹配、可见身形和风格可以共同支持形象判断；高个一项不能推出整体外形很强。现金、净资产、持续收入和偿付负担有不同作用，不能靠无债或资产一项满分代替整个财务分析。

联合规则的来源标识为 `declared_project_conjunctions_not_population_standard`：这是项目选择的可审计条件，不是各国平均人、颜值等级、就业概率或人生价值标准。规则今后可以修订，但应统一版本后重算，不能为了某人的期望结果临时调门槛。

## 如何读 met、limited 和 unknown

本页未另标门槛的项均为 **≥75**。75 沿用 v0.6 对本项“自主有效／明确正向匹配”的内容定义；50、60 等例外在各轴说明，不能统一解释为及格线。

- **AND 路径**：路径中每个条件都满足，才是 `met`。明确不满足任一条件，该路径为 `limited`；其余决定条件缺失或范围跨门槛，则为 `unknown`。
- **替代路径**：任一路径满足即可。没有满足路径、但仍有未决路径时，整体为 `unknown`；全部路径都明确不满足才为 `limited`。
- **候选范围**：整个范围都过门槛才算满足，整个范围都不过才算不满足；跨门槛保留未决。`score: null` 始终按未知处理，不拿区间中点或默认分代替。
- **表现与材料**：`limited` 表示已有条件未达到这条项目组合要求，不自动等于本人缺少某种全部能力。材料多少不乘分；照片或案例的可见范围继续有效。

每轴另列原项 **≤50** 的条件提示，并说明它究竟是任务局限、恢复欠账、容量节点还是所选偏好；这些提示不因平均分较高而消失。50 在财务容量项可能恰好达到一个基础节点，因此不能把所有提示统称为“失败”。未知项进入 `unknowns`，不进入已确认短板。

| `state_code` | 含义 |
| --- | --- |
| `multi_strength` | 所有声明的主要组合都满足，仍受原材料范围限制 |
| `strength_with_constraint` | 有成立的组合或明确核心强项，同时存在关键项的已知制约 |
| `single_strength` | 有成立条件或核心强项，但其他组合条件仍未满足 |
| `pending` | 没有明确失败的组合条件，但决定整体的材料或候选档仍未决 |
| `constrained` | 已知条件限制了主要组合，不能凭其他项推出整体强 |
| `partial` | 当前只能支持部分条件 |

状态是解释标签，不是第七个数字分；不能据此建立人口名次。

## 六轴联合条件与 36 项覆盖

以下每一项至少参加一个联合检查。`core_items` / `support_items` 是本层的阅读分组，不是新权重，支持项同样实际影响结论。

### A 外形条件与呈现

核心 A1 身高尺度、A2 面部/侧貌匹配、A3 可见身形；支持 A4 仪容、A5 风格、A6 表情/姿态。

| 检查 | 明确条件 | 为什么这样连 |
| --- | --- | --- |
| `A.profile` | **A1 且 A2 且 A3**，或 **A2 且 A3 且 A5** | 允许尺度与外形同向，也允许面部、身形、穿搭的匹配路径；高个不是人人必过的唯一门槛 |
| `A.presentation` | A4 且 A5 且 A6 | 仪容、风格和实际呈现承接基础条件，不能用身高替代维护或表达 |

A1 是所选高个偏好；A2/A3 是声明偏好下的可见匹配，不是客观颜值人口分位。全身未拍到的部分保留覆盖缺口，不能否定已见上身，也不能补出未见部分。A2/A3 未知时，A1 高分不能直接推出整体外形成立。

### B 身体功能与当前状态

核心 B1 日常独立性、B2 标准卧推任务、B3 连续游泳任务、B4 动作适配；支持 B5 恢复感、B6 清醒任务精力。

| 检查 | 明确条件 | 为什么这样连 |
| --- | --- | --- |
| `B.activity` | B1≥75、**B2≥60**、**B3≥50**、B4≥75 同时满足 | 日常功能、已选推力、持续任务和动作控制分别有材料，才能谈已观察到的活动底盘 |
| `B.sustain` | B5 且 B6 | 休息恢复与白天任务中的精力影响分别支持持续投入 |

B2 的60是既有训练负荷映射节点，B3 的50是既有连续游泳任务节点；两者都不是全面运动能力常模。强卧推不能消除恢复不足，也不能证明下肢动作适配。B4 候选范围跨门槛时，保留“动作适配待补”，不把它写成已确认失效。

### C 思考与判断表现

核心 C1 理解/迁移、C2 推理/证据链、C3 按风险核验、C4 决策/试验；支持 C5 计划调节、C6 压力后行动。

| 检查 | 明确条件 | 为什么这样连 |
| --- | --- | --- |
| `C.reasoning` | C1 且 C2 且 C3 且 C4 | 学到方法后，需要推理、风险匹配的查证，再用于有边界的判断 |
| `C.regulation` | C5 且 C6 | 把判断带回计划和行动，避免只评“想得明白” |

C3 的明确弱项不能用学习能力补偿；未测数量能力也不能反向判工程逻辑差。一个聊天或一个任务只支持它实际覆盖的风险与领域，不外推 IQ、临床人格或全部判断能力。

### D 实践与协作能力

核心 D1 专业交付/取舍、D2 问题定位/处置、D5 履约可靠性；支持 D3 目标沟通、D4 协作组织、D6 独立办事。

| 检查 | 明确条件 | 为什么这样连 |
| --- | --- | --- |
| `D.delivery` | D1 且 D2 且 D5 | 形成从专业过程、实际处置到可靠收尾的交付链 |
| `D.coordination` | D3 且 D4 且 D6 | 沟通、人员/资源协调和实际办事分别有用，不能只凭职位或人数评管理 |

D5 的明确履约问题不能被头衔或协调高分冲淡。工作交付与个人项目推进保留各自范围，不能把某一场景的成功写成所有生活任务都能执行。

### E 个人经济与缓冲

E1–E6 均为核心条件。金额与比值描述容量和负担，不等同理财能力。

| 检查 | 明确条件 | 对应的实际含义 |
| --- | --- | --- |
| `E.income` | **E1≥50** 且 E6≥75 | 实际经常收入至少覆盖本人必要开支，且所述期间来源有经常收款履约 |
| `E.capacity` | **E2≥50 且 E3≥50** | 本人净资产至少一必要开支年，即时现金至少三必要开支月，形成两层容量 |
| `E.debt` | E4≥75 | 偿付负担未过度挤压经常收入；仅满足这一条件不等于整体财务强 |
| `E.surplus` | **E5>0** | 观察到同期间实际收入留存，不能用必要开支冒充实际总消费 |

这些容量节点来自 v0.6 已声明曲线：不是实证推导出的普遍安全线。E5 未知会阻止“主要财务条件全部成立”，但已知现金、资产、履约与无债条件仍保留；不能把“不知道实际结余”写成“没有结余”。E6 不强制副业，正常单一工资可以在该项获得高分；中断后的缓冲另由资产、现金和资源解释。

### F 可调用资源与约束

核心 F1 家庭支持、F2 居住退路、F3 照护/事务人手、F4 协作渠道；支持 F5 工具/学习资源、F6 责任约束余地。

| 检查 | 明确条件 | 为什么这样连 |
| --- | --- | --- |
| `F.backstop` | **F1≥50** 且 F2≥75 | 可调用支持容量和实际居住使用权分别托底 |
| `F.people` | F3 且 F4 | 现场照护和协作渠道需要能落到实际人手 |
| `F.enable` | F5 且 F6 | 工具可及与当前责任约束共同决定资源能否调用 |

“有钱可以找人”不是现场照护已经落实；付费渠道要有实际可调用依据。资金与住房成立、照护缺口明确时，可以同时给出“托底组合成立，现场人手另有缺口”。不因社交少推人格缺陷，也不因潜在人脉多就视为随时可用。

## 跨轴：评能力链，也保留限制

`overall.established_chains` 保存以下每条链的 `result`，**数组名不代表每条链已经成立**；展示前应读取 `met / limited / unknown`。

| 链 | 联合条件 |
| --- | --- |
| 认知→问题解决→可靠交付 | C1、C2、C3、C4、D1、D2、D5 均≥75 |
| 本人缓冲→家庭/居住托底 | E1≥50、E2≥50、E3≥50、E4≥75、E6≥75、F1≥50、F2≥75 |
| 调节→沟通组织→独立办事 | C5、C6、D3、D4、D6、F4、F5 均≥75 |

经济托底链只说明已知基础抗冲击条件，不含“永远财务安全”或“持续结余已经证实”。恢复与清醒精力、证据核验、计划调节、可靠履约、日常收入覆盖、现金、偿付、现场人手、协作和责任约束的已知局限另列 `constraints`。目标工作语言、资格或迁居适配未核实，进入 `unknowns`；不能写成语言差或能力缺陷，也不扣通用思考与专业分。

## 地区坐标和本人实际条件分开

地区原六维参考分继续按 v0.6：有依据时 A1 换成相对所选均高的突出坐标，E1 换成名义收入相对当地工资坐标；其余规则保持。原地区分数不由 v0.7 联合层覆盖。

但这两个地区项的**含义变了**，不能直接套用本人原始条件门槛：

- 地区 A 的联合检查沿用全局 A1 所选高个偏好；`A.local_stature` 在 `contextual_references` 单列本人身高、参照均高、厘米差、地区原分和来源。`met` 仅表示不低于所选均高，不能改称整体吸引力或人口名次。
- 地区 E 的联合检查、瓶颈和经济托底链均沿用全局 E1–E6 的**实际收支与容量**。`E.local_income` 单列本人税前年化÷所选当地税前工资参照；`met` 只表示比值≥1，`limited` 只表示低于这条工资坐标，不表示本人现实入不敷出。

地区参照不纳入联合状态。没有当地语言、工作资格、真实报价、消费预算和现场资源信息时，不能把同币种收入比值写成当地可获工资、生活能撑多久、落地竞争排名或迁居成功率。数字与联合解释采用不同口径时，必须同时显示 `comparison_basis`，让读者知道自己在比较什么。

## 资金层：所有权、可用性与用途不混算

`calculate_context(financial_facts)` 返回 `financial_context`，只做容量解释，不给新分数。字段缺失保留 `null`，不从资产总额、稳定工资或家庭状况猜出余额。

| 层次 | 字段 / 计算 | 去重与边界 |
| --- | --- | --- |
| 本人现金总额 | `cash_total_cny` | 本人净资产中已含该现金，不再加一次 |
| 即时自由现金 | `liquid_cash_cny`，可为区间 | 是现金总额的子集，不能大于现金总额 |
| 现金中其余部分 | 总现金−自由现金，输出 `restricted_cash_cny` | 属推导差额；不凭差额推断产品、到期日、提前支取条件或“专门应急金”用途 |
| 明确专款备用金 | `earmarked_emergency_fund_cny` | 只有已确认用途才标专款，不自动把所有存款或差额叫备用金 |
| 本人净资产 | `personal_net_assets_cny`、`asset_date` | 含本人现金与其他资产后的原快照；保留日期，不自动重估或全部视作即时可花现金 |
| 家庭支持 | `family_support_cny`、可调用性、所需天数 | 仍归家庭资源，不提前并入本人资产或即时现金，也不保证无条件到账 |

提前支取未核实时，现金中其余部分不加入“立即可用”的月数；明确可提前取得时，可以另示全现金容量，但仍与自由现金区分。家庭支持、住房使用权和照护人员不能互相自动替代。

`income_necessary_coverage = 税后月收入 ÷ 必要月开支`，`liquid_buffer_months = 自由现金 ÷ 必要月开支`。这两项不是实际储蓄率，也没有纳入未说明的大额消费、旅游或迁居成本。实际总消费未知时 `actual_spending_known` 保留未确认。

### 3 / 6 / 12 个月是压力诊断窗口

引擎分别计算“收入暂为零、必要开支不变”时三个窗口需要的金额，并列自由现金差额和盈余：

- `necessary_cost_cny = 必要月开支 × 窗口月数`。
- `liquid_gap_cny` 为窗口所需金额减自由现金后的非负缺口区间；`liquid_surplus_cny` 保留可正可负的余量。
- `covered` 表示整个现金区间均覆盖，`not_covered` 表示整个区间均不足，`conditional` 表示区间跨过窗口，缺关键输入为 `unknown`。

这些窗口便于看现金结构怎样承受收入中断，**不是“每个人都应该存够某个月数”的通用建议**，也不是对失业概率、投资回报或家庭援助的预测。

### 住房退路是条件杠杆，不是目标城市真实预算

仅当已确认可用的住房退路、原必要开支和当前房租都有输入，且房租小于必要开支时，计算 `fallback_housing_scenario`：从当前必要开支中移除当前房租，展示现金月数的条件变化。

它明确假设：当前房租停止、替代住房无租金、其余成本不变、暂不计搬家/退租成本、原收入不自动迁移。它不表示目标城市的吃住交通预算已经调查，也不保证原工作或薪资能保留。展示时应称“免去当前房租的条件演算”，不能写成已经测得的异地真实生活成本。

## 调用与页面呈现

```python
from review_v06 import calculate_report
from joint_review import calculate_joint
from joint_context import calculate_context

scored = calculate_report(report)
enriched = calculate_joint(scored)  # 深拷贝，保留原数值；可重复调用
enriched['presentation_version'] = 'joint-profile-v0.7'
if isinstance(enriched.get('financial_facts'), dict):
    enriched['financial_context'] = calculate_context(enriched['financial_facts'])
```

`render_dashboard.py` 在 `presentation_version` 为 `joint-profile-v0.7` 时依次完成 v0.6 算分、联合判定和可选资金情境计算，自动选 `assets/dashboard-v07.html`。无需手动往事实档案写入派生分；未加该呈现版本的 v0.6 报告继续使用原模板。

每轴输出 `state / state_code / core_items / support_items / checks / strengths / bottlenecks / unknowns / coverage_note / comparison_basis / contextual_references`。每条检查带条件、实际读数、三态结果和理由。页面应先给短评、六维数字及图形，再给综合能力链、资金层、每轴判断和地区多条件解释；账本与来源供展开核对。明确证据、所选偏好和综合推断各自范围，避免把一串指标复述当作综合评价。

以下 PowerShell 演示仅复用现有 [虚构输入](../examples/review-v06.json)，不使用真人档案，不改写原示例。从 Skill 根目录执行：

## 验证范围与继续修订

回归检查覆盖：单项高身高不能代替外形组合、非高个替代路径、未知不是低能力、恢复不被力量取消、无债/现金不能单独推出财务强、照护不被资金抵消、全部 36 项参与、原输入分数不变、幂等，以及地区工资/身高口径分离。

软件检查说明实现遵循声明规则；它没有证明这些门槛最优、不同评阅者一致、能预测现实成功或已获用户体验验收。后续应依真实重复使用、独立复评和明确反例修订规则，保留历史版本与原观察日期。
