# 人生方向：生活取向、行动与反馈

本板块独立于六维评分，连接“想过怎样的生活”和“已经怎样行动”。它可以整理价值偏爱、生活方式、探索兴趣、现实目标与取舍，不要求每个人都有宏大理想、赚钱目标或固定职业路线。

## 五组问答

问卷入口为[life-direction-items.json](life-direction-items.json)。每次只推进一组，先读已有资料与本人的最新回答；已知材料带原日期复用，真正缺失的再问。

| 组 | 主题 | 需要区分 |
| --- | --- | --- |
| L1 | 想过怎样的生活、偏爱、理由与取舍 | 本人想要/想探索的，与他人期待不同；喜欢过程与想要结果不同；历史排序与当前选择不同 |
| L2 | 方向形成、首次行动与持续轨迹 | 想法形成、开始行动、记录和最近复核是不同日期；不知道的日期留null |
| L3 | 一个实际周期的计划、行动与产出 | 计划与事实不同；工具产物不等于本人掌握，投入小时不等于成效 |
| L4 | 卡点、调整、中断与恢复 | 可控因素与外部条件不同；合理休息/转向不是不自律 |
| L5 | 结果反馈、归因及继续/调整/停止条件 | 结果好坏不单独证明自律，长期坚持不单独证明方向合适 |

人生方向总览可以先保存探索状态，再选择本人想具体讨论的方向。其他兴趣保留为兴趣，不自动变成承诺。每组允许部分回答、未知与本轮跳过。已有积极线索且一个区别可能改变判断时，再中立追问；不能因答案简略判低，也不要求截图或第三方隐私。

## 私人存档与连续性

使用`scripts/life.py --state-dir PRIVATE_ROOT`，`PRIVATE_ROOT`与六维本人目录一致。人生档案实际保存在`PRIVATE_ROOT/life-direction/current.md`，与六维`PRIVATE_ROOT/current.md`使用独立修订号。不会修改原36项、评分、历史或旧问卷版本。

每条回答先保存再继续。状态按同一方向ID与L1–L5分组，事实带`value/unit/observed_at/source/note`，同六维事实约定。未来可在某个方向的某一组局部更正，不需要重做所有问题；每次写入保留旧快照。修订冲突、损坏档案和路径错误必须报告并保留原件，不能重置覆盖。

导入旧资料时保留原始日期和来源，旧进度/目标标明待复核，不能因导入当日自动认定仍在实行。不要把所有项目同日确认成当前主线，也不要把生成报告等同于本人执行了建议。

## 与六维结合

对每个方向说明：

1. 本人的生活取向/目标和理由，当前是探索、尝试、推进、调整或待复核。
2. 已发生的行动与结果，未知的形成时间、首次行动或成效分别留空。
3. 六维里哪些已有条件可用，哪些实际限制会卡住这一目标；只作有材料的关联，不额外改权重或重复加分。
4. 下一步最值得做的一两件事、现实效果如何判断，以及真正需要本人补充的事实。

方向不同，六维相关性不同。已有优势可以直接使用，不要求六项同时补短板。建议仍遵循[现实提升与评测维护](improvement-actions.md)，不能用“再填材料、补更多照片”代替推进本人想做的事。

## 观察与分数

页面用文字分别说明目标取向、行动兑现、持续/调节和成效反馈，保留各自的材料与限制。当前没有给人生方向新增数值规则，`score`为null；探索状态不是零分，也不生成第七轴或人格“自律总分”。某个领域的规律行动只支持该领域，不自动推广到所有生活场景。

## 页面协议

总报告保留`version: weighted-character-v0.6`，新呈现为`presentation_version: life-direction-v0.8`。顶层新增`life_direction`，其`version: life-direction-report-v1`、`source_revision`引用人生档案独立修订；原顶层`source_revision`仍引用六维档案，不能混用。

`life_direction`包含生活总览`overview`、文字观察`observations`、各方向`directions`和续问`interview`。方向卡可包含形成/首次行动日期、带时效说明的轨迹、`axis_links`、目标建议和未决事实；`axis_links.axis_id`仅引用A–F，不能改写对应分数。所有真实事实和报告留私人目录，公开案例只能使用明确标注的虚构材料。

HTML只呈现材料和下一问，聊天里的实际回答通过存档器逐组保存。离线页面不假装能在没有本地保存工具的情况下自动更新Markdown；后续生成报告时核对人生源修订号，避免旧页面被误认成最新结果。

完整虚构案例：[输入及逐组命令](../examples/life-direction-input.md) → [实际CLI保存/续测/更正输出](../examples/life-direction-output.md)。人物与经历是编写材料，命令和历史回读已实际执行；这不证明真人长期目标或生活改善效果。
