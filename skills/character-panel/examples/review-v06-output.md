# v0.6虚构案例：输出与使用方式

**所有人物和输入均为编写的演示；计算在2026-10-27通过真实引擎运行，不是真人测评或量尺校准。**

输入见[review-v06.json](review-v06.json)。目标是演示36项原值/内容档、独立覆盖、数值重算及六轴输出。为保持字段演示简洁，行为项刻意设为满足各题75档，不能照搬这种分布替人打分。

运行：

```text
python scripts/render_dashboard.py --data examples/review-v06.json --output PRIVATE_OR_TEMP_PATH/example.html
```

将`PRIVATE_OR_TEMP_PATH`替换为私人或临时目录。本例不需要真人照片或API。

| 轴 | 项目分 | 可评权重 |
| --- | ---: | ---: |
| A 外形条件与呈现 | 73 | 100.0% |
| B 身体功能与当前状态 | 70 | 100.0% |
| C 思考与判断表现 | 75 | 100.0% |
| D 实践与协作能力 | 75 | 100.0% |
| E 个人经济与缓冲 | 69 | 100.0% |
| F 可调用资源与约束 | 75 | 100.0% |

可选均衡读数：72.893728，显示73。它不是人口平均或人生价值。

每一项的未取整值、两层权重、内容规则、覆盖与贡献由引擎生成，渲染器自动选择v0.6模板。输入对象与原材料日期不被改写。

## 关键边界演示

- 将某行为项材料删除：分数未知，不默认50/75，也不推能力差。
- 同一表现多给一张图或多写一段话：覆盖可变化，分数不因此自动增加。
- 将F1改为明确不可用：即使潜在金额很大，该项也为0，容量不能平均补偿不可用。
- 相邻内容档尚未分清：带具体range_reason保留候选范围与中立追问，不填区间中点。
- 地区工资只改变E1坐标；真实资产年数、现金月数和家庭调用容量不跟工资重复变分。

本例运行验证了包装、数值和渲染路径，不验证评分心理测量效度；浏览器截图与真人体验应在各次交付中分别报告。
