# 示例输入：中断后只重测一项

案例性质：**编写的虚构演示输入**。人物、数值和经历均为演示编写，不是真人资料，也不证明评分有效。对应的实际命令与生成结果见[output.md](output.md)。

## 背景与目标

一位成年使用者想先记录基础信息和身高，接着收集工作案例；暂不上传照片，也暂时没有收入或资产资料。他希望每次回答都保留下来，停止后能恢复，之后只重测身高。

## 分轮输入

1. “这是为我本人建的档案，我已成年。出生年份是1994，目前住苏州，做工业产品设计。可以叫我小禾；性别先不填。”
2. “身高172厘米，本人自报，记不清测量时间和条件。先不要猜分数。”
3. “我想先测实践能力。我主要做家用产品的结构设计，最近做过一个便携收纳盒。”只给出领域和案例开头，具体贡献与验证尚待补充，应保存草稿，不标完整作品评价。
4. “先到这里，下次接着说。”
5. 重新打开存档：“接着刚才的工作案例。收纳盒的扣合结构是我设计的，用3D打印样件迭代了两次；同事负责外观。开合测试记录了200次，暂没完成量产验证。”
6. “只复测A1。2026年10月18日早上脱鞋靠墙测了两次，都是171.5厘米。其他项目先不动。”

日期属于虚构输入中声明的观察日期；运行时保存时间由工具据实生成。不能把示例日期用到真实使用者身上。

## 演示约束

- 基础信息独立，不计入36项填写数量。
- A1有数值但规则未定，`score`必须是 `null`。
- D1分两次回答，中断前保存已有领域和案例草稿；补充后保留本人贡献、他人贡献与量产验证缺口。
- 未上传照片，A2—A6仍未开始/待材料，不能标成已评或低分。
- 暂停保留续测位置；局部复测保留旧身高快照，其他项目保持不变。
- 不输出人生总分、六轴分或人口百分位。

## 检查点

读取 `status`能找到相同档案、修订和续测位置；当前档案能追溯回答和日期，历史能找到旧身高。使用过期修订号保存应失败，旧答案不被覆盖。完整执行证据以对应输出记载的实际命令和生成结果为准，不因本输入写了预期行为就称为已验证。
