# 扣子空间：与 Agent 协作完成任务

**能力：** 官方介绍将扣子空间描述为用户与 Agent 协作完成任务的环境，包含搜索、分析、任务执行、探索/规划模式及扩展能力。[官方介绍](https://docs.coze.cn/guides_coze_space_release)

**适用：** 希望通过现成 Agent 推进一项研究或办公任务时，可与其他现成产品一起比较；不据此假定用户需要自己搭建工作流。

**条件与限制：** 本条依据产品介绍，不等于每种任务均能可靠完成。产品命名、当前入口、功能开放、付费和具体扩展要求需按使用时核对；不要将“扣子空间”和“搭建扣子应用/工作流”的操作混为一步。

**核验范围：** 2026-10-21 实际阅读上述官方介绍正文；未激活账户或执行任务，不采信其中无限能力或专业效果的宣传为实测事实。

**待核实：** 用户所需扩展、地区/账户与素材处理条件。产品入口：[扣子](https://www.coze.cn/)；从官方介绍指向的当前使用说明继续确认具体模块。
