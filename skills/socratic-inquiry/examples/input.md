# 输入：不学习就没上进心？

性质：为解释方法编写的虚构演示，不是真实用户对话或实测记录，不含真人资料。

## 用户原始问题

> 我觉得下班后不学习的人都没上进心。我自己有时也不学，所以会觉得自己很差。请用苏格拉底式追问帮我想清楚，严格一点，多问依据，也主动找反例。

## 上下文

- 用户只观察过少数熟人，没有调查数据。
- “学习”是否只指上课、读书尚待澄清，不能先替用户决定。
- 用户想检验自己的判断，不是要给熟人贴标签或让他们认输。
- 不引入真人姓名、工作单位或私密经历。

## 约束与预期

- 通常一次一个核心问题，根据回答推进，不发问卷。
- 用户可以修正说法、保留价值取向或承认不知道。
- 用户要求直接回答、停止或总结时照办，不强推行动计划。
- 无网页、文件或 API 工具；涉及人群频率时承认缺少资料。
- 对应 [输出](output.md) 是预先编写的完整对话，用于检查规则是否被表达，不作为效果证据。
